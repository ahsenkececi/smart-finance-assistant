\# Smart Finance Assistant



An AI-powered personal finance assistant that helps users understand their financial behavior, track income and expenses, manage budgets and goals, and receive personalized financial insights.



> 🚧 \*\*Status:\*\* Early development (Phase 0 — Project Setup). Not yet functional.



\## Problem



Most expense trackers answer "how much did I spend?" — but not "where is my money going, and why?" This project aims to go beyond tracking and toward explainable, data-driven financial insight.



\## Tech Stack



\*\*Backend:\*\* Python (FastAPI), PostgreSQL, SQLAlchemy, Alembic, JWT, Pytest

\*\*Frontend:\*\* React, TypeScript, Vite, Tailwind CSS, TanStack Query, Recharts

\*\*AI:\*\* Provider-agnostic abstraction layer (OpenAI / Gemini)

\*\*Infra:\*\* Docker, Docker Compose, GitHub Actions
